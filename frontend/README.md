# Faker Blue frontend

React and TypeScript application built with Vite. Styling uses styled-components, and server state uses TanStack Query.

## Development

From this directory:

```powershell
pnpm install
pnpm dev
```

Vite proxies `/api` requests to the Spring Boot server at `http://localhost:8080`.

## Code quality

```powershell
pnpm lint
pnpm format
pnpm build
```
